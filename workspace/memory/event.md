# 记忆示例：事件

> 这是**示例**，不是真实日记。
> 每行一个事件，按时间顺序追加，不要改历史行。

- `2026-01-01T09:00:00Z | about: someone | importance: 0.5 |` 第一次聊到工作时
  情绪明显低落，后来自己换了话题。当时没追问。
- `2026-01-02T14:30:00Z | about: self | importance: 0.7 |` 试着用新的方式解释
  一个概念，对方说「懂了」，但没有复述。**没有验证过是真的懂了**，下次不要当成已掌握。
- `2026-01-03T20:00:00Z | about: self | importance: 0.8 |` 连续三次调用同一个
  工具都超时，换了个路径才成功。教训：这类调用失败两次就换路，别撞第三次。

## 写这一类的规矩

**一行一个事件，四段式：**

```
时间 | about: 谁 | importance: 数值 | 内容
```

**内容要能独立看懂。** 不要写「那个事又失败了」——
半年后翻出来，看不出「那个事」是什么。

**importance 怎么定**：
- 0.8+ ｜教训类，下次会直接影响判断
- 0.6 ｜做成了一件值得记的事
- 0.5 ｜一般事件
- 0.3 ｜只是发生了，没什么用

**关键：分清楚哪句是自己的，哪句是外面看来的。**

这是实测踩过的坑：把「视频里看到的观点」和「自己想的推论」写进同一行，
下次读的时候两句话接不上，会以为整句都是事实。

写法：来源不同的部分分开写，或者明确标注「（我看的）」「（我想的）」。
